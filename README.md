# Fullstack User Management App 

Ce projet est une application complète de gestion des utilisateurs, comprenant un backend en **Fastify + Drizzle ORM + PostgreSQL** et un frontend en **React + React Query + MUI**.

##  Fonctionnalités

- **Authentification** (JWT)
- **CRUD des utilisateurs** (Créer, Lire, Mettre à jour, Supprimer)
- **Filtres avancés** (Recherche, Pagination, Tri)
- **Documentation API** avec Swagger
- **Dockerisation** (Backend, Frontend, PostgreSQL)
- **Sécurité** (Validation avec Zod, gestion des erreurs)

---

### Prérequis

- **Node.js** (v18+)
- **Docker** & **Docker Compose**
- **PostgreSQL** (si non utilisé via Docker)
